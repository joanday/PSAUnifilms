## 🚀 Key Implementations

### 1. 🤖 AI Integration (Objective 2 Completed)
- **Problem:** Original objective required Vertex AI and Video Intelligence APIs, which mandate a Google Cloud Billing account and credit card, creating a barrier for the student project.
- **Solution:** Pivoted to **Google Gemini 1.5 Flash AI** via the `google_generative_ai` package (Version `0.4.7`). This runs entirely client-side and utilizes the free Google AI Studio tier.
- **Code Changes:**
  - Created `AiService` (`lib/services/ai_service.dart`) to interface with Gemini.
  - Implemented prompt engineering to automatically analyze film title and description to output JSON containing a `summary` and `keywords`.
  - Updated `Film` model (`lib/models/film.dart`) to persist `aiSummary` and `aiKeywords` in Firestore.
  - Updated submission screens (`submit_film_screen.dart`, `submit_screen.dart`) to invoke `AiService` asynchronously before pushing to Firestore.
  - Updated `film_detail_screen.dart` to display an "✨ AI Insights" UI block presenting the generated data.

### 2. 🎬 Metadata Completeness (Objective 1 Completed)
- **Problem:** The submission forms and Firestore schema were missing the "Director" field, which was explicitly required by Draft 15 objectives.
- **Solution:** Added Director input.
- **Code Changes:**
  - Updated `Film` model to include `director`.
  - Added `directorController` and a text field to both `submit_film_screen.dart` and `submit_screen.dart`.
  - Updated `devcom_dashboard_screen.dart` `FilmSubmission` model to map the director field for officer review.
  - Updated `film_detail_screen.dart` to display "Directed by [name]" below the year/genre tags.

### 3. ⚡ Auth & Navigation Bug Fixes
- **Problem 1 (Slow Logout):** When logging out from the profile or dashboard, the app would freeze or lag significantly.
  - **Fix:** Identified a race condition between manual `Navigator.pushReplacement` and the `authStateChanges` stream listener in `main.dart` (`_RoleGate`). Removed manual navigation. `FirebaseAuth.instance.signOut()` now instantly triggers the `_RoleGate` to show the login screen.
- **Problem 2 (Guest Access):** The app still allowed unauthenticated users to enter via "Continue as Guest", bypassing the intended role-based access.
  - **Fix:** Removed the "Continue as Guest" `GestureDetector` entirely from `login_screen.dart`.

### 4. 🔔 Push Notification Toggle Fix
- **Problem:** The notification toggle on the profile screen only changed a local boolean and didn't actually affect push notifications.
- **Solution:** Wired the UI switch directly to FCM topic subscriptions.
- **Code Changes:**
  - Added `shared_preferences` and `firebase_messaging` logic to `_ProfileScreenState`.
  - Created `_toggleNotifications(bool enabled)`:
    - If true: `FirebaseMessaging.instance.subscribeToTopic('new_uploads')`
    - If false: `FirebaseMessaging.instance.unsubscribeFromTopic('new_uploads')`
  - Persisted the user's choice using `SharedPreferences` so it survives app restarts.
  - Set default state to ON (`true`).

### 5. 🛡️ Content Protection Verification (Objective 5)
- **Investigation:** User reported screen recording was black (functioning as intended) but thought the feature wasn't implemented.
- **Finding:** Verified that `WindowManager.LayoutParams.FLAG_SECURE` is properly active in native Android code (`android/app/src/main/kotlin/.../MainActivity.kt`). Objective 5 is confirmed 100% complete.

### 6. 🎨 Home Screen UI/UX Overhaul
- **Problem:** The home screen layout was static and cluttered, with a single featured film and horizontal scrolling that didn't effectively showcase the library.
- **Solution:** Redesigned key sections to feel more like a premium, dynamic streaming platform.
- **Code Changes:**
  - **Rotating Monthly Showcase:** Upgraded the static `_featuredBanner` to a custom `ShowcaseBanner` widget (`lib/widgets/showcase_banner.dart`). It automatically queries all films uploaded in the current month and uses a `Timer` to seamlessly cycle through 6-second clips of each film, starting at the 10-second mark to bypass intros.
  - **Player Interaction Block:** Wrapped the YouTube iframe inside an `AbsorbPointer` so users are routed directly to the `FilmDetailScreen` upon tap, rather than being hijacked into the YouTube native app or website.
  - **Covering YouTube UI:** Injected a dark top-gradient overlay to visually obscure the native YouTube title and uploader profile icons, making the embedded player look like a first-party native video player.
  - **"All Documentaries" Grid:** Replaced the horizontal `ListView` in the 'All Documentaries' section with a responsive `Wrap` grid using portrait-oriented (2:3 aspect ratio) posters. Simplified the metadata strictly to the film title for a minimalist aesthetic.
  - **Cleanup:** Removed redundant "View All" buttons from the showcase and newly uploaded sections.

### 7. ?? Showcase Banner Crash Fix
- **Problem:** App crashed when updating ShowcaseBanner due to a double-dispose of the YoutubePlayerController.
- **Solution:** Nullified the controller in the disposal flow so that it isn't incorrectly accessed by the widget tree after the framework disposes it.

### 8. ??? AI Metadata Fallback
- **Problem:** When the Gemini API returned a 403 Permission Denied error (due to restricted or exhausted quota on the user's Google Cloud project), submitting a film would fail completely.
- **Solution:** Modified i_service.dart to catch the exception and return fallback mock metadata. This guarantees students can still submit films and complete their workflow even if the Google API goes down or blocks the key.

### 9. ?? Semantic Search (Objective 3 Completed)
- **Problem:** Search didn't include the AI-generated keywords, missing out on semantic matches.
- **Solution:** Updated the _results filtering logic in search_screen.dart to cross-reference the user's query against the iKeywords list attached to each film, fulfilling the Semantic Search requirement.

### 10. ?? Custom Notification Icon & Theming
- **Problem:** Android forces status bar notification icons to be solid white shapes with transparent backgrounds. Because the app's logo had a solid green background, notifications appeared as blank white squares.
- **Solution:** 
  - Wrote a Python script utilizing Pillow to isolate the yellow laurel branch and camera aperture from the logo.
  - Converted the isolated shapes into a crisp white silhouette, applied a dilation filter to thicken thin lines, and saved it as ic_notification.png.
  - Wired AndroidManifest.xml and lutter_local_notifications to use this new silhouette.

### 11. ?? Returned Documentaries Workflow (Objective 6 Related)

- **Solution:**

Updated devcom_dashboard_screen.dart and cm_token_service.dart to fire a personalized push notification specifically to the submitter when their film is marked as 'Returned'.

### 12. 📂 "My Submissions" UI/UX Refactor
- **Problem:** The newly added "Returned Documentaries" and "My Submissions" lists on the Profile screen cluttered the main view, and an unresolved composite index error broke the view entirely.
- **Solution:** 
  - **Firestore Index Fix:** Removed `.orderBy('createdAt', descending: true)` from the Firestore stream and handled chronological sorting locally in Dart (`films.sort((a, b) => b.createdAt.compareTo(a.createdAt))`) to bypass the `FAILED_PRECONDITION` index requirement entirely.
  - **Screen Segregation:** Extracted the visual layout for submissions into a dedicated `MySubmissionsScreen`.
  - **Role Gating:** Nested the access point to this new screen inside the Profile's "Account" section as a menu tile. Dynamically gated this menu tile so it is strictly visible only to users bearing the "CAS Student" role.

### 13. 🤖 CBVR AI Model Upgrade & Semantic Search UI (August 27, 2026)
- **Problem 1 (Model Error):** The app hit API version mismatches and 'overloaded' errors when attempting to use older models like `gemini-pro` and `gemini-1.5-flash` with the current SDK.
- **Solution 1:** Migrated `CbvrService` and `AiService` to use `gemini-3.6-flash`, correctly aligning with the supported generative models.
- **Problem 2 (Hidden Navigation):** The Smart Search screen was practically inaccessible from the new tab structures.
- **Solution 2:** Embedded ✨ Smart Search directly into the top search bar of the main Home Screens.
- **Problem 3 (Too Strict CBVR & UI Bug):** Searching implicit concepts like "batang ina" returned 0 results because the AI required exact wording. Also, returning 0 results crashed the UI back to the default home screen.
- **Solution 3:** 
  - Adjusted `CbvrService` to lower the minimum threshold (`minScore` = 15) and explicitly instructed the AI prompt to map terms like "girl" or "batang ina" semantically.
  - Fixed the widget tree in `home_screen.dart` and `student_home_screen.dart` to explicitly handle and display an empty AI results state.
